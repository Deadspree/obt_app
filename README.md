# Orange ball tracking app
Streamlit app for orange ball trajectory detection
## Device Requirements
* OS: Windows 10/11
* Language: Python 3.10
## Setup the app
* Clone the repository
```
git clone https://github.com/Deadspree/obt_app.git
```
* Install the required library
```
pip install -r requirements.txt
```
## Use the app
* To open the app
```
streamlit run app.py
```
